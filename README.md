# Permalink Rule Assist

**版本：** 1.0.0

依分類／標題規則產生 ASCII 文章 slug（例如 stock-watch-YYYY-MM-DD），不改站點永久連結結構。

## 需求

- WordPress 6.0+
- PHP 8.0+（部分外掛標示 7.4+）

## 安裝

1. 下載本倉庫 zip，或 clone 後壓縮成資料夾
2. 上傳到 `wp-content/plugins/permalink-rule-assist/`
3. 在後台啟用外掛
